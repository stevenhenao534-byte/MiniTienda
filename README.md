 Mini Tienda de Licores Artesanales Macerados

Mini sistema de compras desarrollado en C# para practicar Git y GitHub.

 Funcionalidades

- Ver productos
- Agregar productos al carrito
- Ver carrito
- Calcular total
- Finalizar compra

 Tecnologías

- C#
- .NET
- Git 
- GitHub

 Flujo de trabajo

- feature/productos
- feature/compras
- Pull Requests
- Code Review
- Merge hacia main
